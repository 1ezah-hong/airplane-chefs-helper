## 2. 用户端整体视觉语言

玩家端采用克制的航空导航感，而不是拟物化游戏界面：浅雾蓝环境、深海军蓝信息与主操作、白色半透明玻璃表单卡，以及金币金 / 钻石青作为资源语义色。数值层级高于装饰；所有目标、收入、成本、预算、状态均必须有文字标签。

- **引入页：** 明亮的天空渐变、淡化航线 / 城市轮播内容与居中的纽约入口，强调“从城市进入”。
- **计算页：** 可滚动的浅蓝渐变页面；固定半透明头部与底部提交区包围一张连续填写的单列表单。
- **结果页：** 更克制的浅蓝实底与白色结论区块。成功为蓝色正向提示；无解为柔和珊瑚红提示，均不只依赖颜色传达状态。
- **覆层：** 背景暗化并模糊；前景为乳白玻璃确认弹窗。

## 4. 页面基础尺寸与 mobile-first 规则

- **基准画板：** 宽 `403px`，常规视口高 `875px`；页面背景覆盖全宽。计算页与成功结果是按内容增长的纵向滚动页面，Figma 内容高度分别为 `1811px` 与 `1069px`。
- **移动布局：** 单列，正文左右各 `16px`，无非必要横向滚动。城市路线轮播是唯一允许横向滑动的玩家端区域。
- **固定区域：** 计算页使用约 `80px` 高的顶部 Header；底部操作条采用模糊半透明处理，正文须保留对应底部安全空间，避免 CTA 遮住纪念品或校验信息。
- **最小 / 最大宽度、桌面容器最大宽度和具体断点：** **待确认**。Figma 仅提供约 403px 宽的玩家端画板；不得从截图臆造桌面数值。

## 5. 引入页视觉规范

### 5.1 结构与布局

1. 全幅天空渐变与轻微径向氛围光；顶部无传统导航栏。
2. 品牌位于距顶部约 `164px` 的左侧 `24px` 对齐区域：品牌显示两行，slogan 在其下方 8px。
3. 城市路线覆盖全幅。选中城市内容位于页面中下部：欢迎语、城市名、主 CTA 垂直居中；底部显示“左右滑动，浏览完整城市路线”。
4. 轮播视觉使用连续无边界场景，不使用城市卡片、网格、描边、阴影或城市卡片间距。底部白色渐变面纱从约 `y=350px` 起覆盖并使用 Background Blur `48`，确保文字可读。

### 5.2 城市状态

- 首次进入时纽约必须默认选中、居中，可露出相邻场景边缘。
- 纽约：显示“欢迎来到”、`纽约`、主按钮“点击进入 →”。城市名使用 `type/display/city`，按钮为深色圆角胶囊，Figma radius 为约 `17.96px`，深色阴影如 Token 表。
- 未开放城市：沿用连续轮播与淡化的欢迎语 / 城市名。状态文字“暂未开放”必须按 UX-SPEC 展现且不可进入计算器；其**具体字级、标签形态、定位、分页点造型与场景素材规范均为待确认**，因为当前 Figma 未清楚给出这些状态细节。
- 加载骨架、资源失败重试：遵守 UX-SPEC 的逻辑；其视觉参数为**待确认**。

## 6. 纽约计算页视觉规范

### 6.1 页面框架

- 背景为 `gradient/page/calculator` 加淡蓝径向氛围光。
- Header 为半透明白（45%）玻璃层，约 `80px` 顶内边距、左右 `16px`、底部 `12px`；包含返回箭头、11px 加字距产品名、17px 当前城市标题。底部细边框为半透明白。
- 正文从 Header 下方 20px 开始，依序呈现：当前状态、资源预算与偏好、食物升级候选、纪念品、草稿说明及计算按钮。此顺序固定遵循 UX-SPEC。
- 当前状态区默认展开；食物与纪念品可折叠。折叠 / 展开行为、校验触发与自动定位完全按 UX-SPEC；Figma 的展开箭头转场动效参数为**待确认**。

### 6.2 当前状态与预算

- Section 用 Glass Card，顶部有深色圆形步骤号（`12px Semi Bold`）。
- Select 宽约 `337.49px`、高 `48.5px`；数字输入高约 `52.49px`；均为 12px 圆角、90% 白底与 `#D6E2ED` 0.75px 边框。
- 三星目标为不可编辑指标行：左侧金币色三星标记与标签，右侧使用 `20px Bold` 数值。
- 金币 / 钻石预算为并列的两个输入。在较窄空间不得并排时，按 UX-SPEC 的单列规则堆叠；其触发宽度为**待确认**。
- 成本偏好使用两项 Segmented Control（详见第 13 节）。它仍是必选业务字段；没有选中时的完整提交前视觉状态为**待确认**。

### 6.3 食物与纪念品

- 食物候选区遵循目录固定顺序，未选行高约 `49.97px`、radius 16、40% 白底、`#E1EAF2` 0.75px 边框。

- 食物行从左到右为 Checkbox、名称、右对齐分类标签。标签底 `#E7EFF6`，高度约 25，使用 `11px Medium` 分类文字。
- 纪念品行沿用 Checkbox 与名称 / 辅助说明组合，不为玩家提供“使用数量”输入。允许后显示库存输入和 UX-SPEC 指定文案。
- Figma 样例未完整画出纪念品“允许后库存输入”的展开态，除共用 Input 视觉外的行高与展开容器参数为**待确认**。

### 6.4 草稿与提交

- 草稿静态说明采用 12px Regular、低强调蓝灰文字；“清除草稿”为 13px Medium 次级文字操作，不得伪装为危险主按钮。

- 计算中需禁用重复点击且显示“计算中”状态，依 UX-SPEC 保留既有输入。spinner 形态 / 动效时长为**待确认**。

## 19. 响应式视觉规则

1. 以 403px Figma 画板为首要还原目标。所有正文单列、表单、结果与弹窗在常见手机宽度无页面横向滚动。
2. 城市路线可横向滑动；其他页面区域不得产生横向滚动。宽屏可显示更多相邻城市场景，但不能降级为城市卡片列表。
3. 食物展开字段在移动端按 Figma 垂直排列；UX-SPEC 允许窄屏纵排、宽屏可排列得更紧凑，但具体桌面字段栅格、容器最大宽度和断点为**待确认**。
4. 计算页在宽屏仍维持可读单列表单宽度，不新增侧栏；成功页可按 UX-SPEC 在宽屏并列顶部指标 / 清单 / 成本卡，但具体并列宽度、间距、断点为**待确认**。
5. 固定 Header、底部 CTA 与弹窗均需适配设备安全区；Figma 未标记安全区 inset 的具体值，故为**待确认**。
